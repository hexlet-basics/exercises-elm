Изучать язык программирования, по традиции, начинают с программы 'Hello, World!'.

```text
Hello, World!
```

В языке Elm эта программа будет выглядеть так:

```elm
module Main exposing (main)

import Html exposing (text)


main =
    text "Hello, World!"
```

Текст `Hello, World!` появится на экране благодаря функции `text`.
